# HOCHO

一个 Chrome 插件形式的 AI 陪伴工具：点开弹窗就能和选定的角色语音聊天，TA 能看到你正在看的网页、听懂网页里视频在演什么，也能通过摄像头看到你。底层使用 [MOSS-Live](https://platform.moss.cn/docs/models/moss-live)（`moss-live-1.0`）。

当前版本：0.7.0

## 怎么用

1. 打开 `chrome://extensions`，开启右上角「开发者模式」，点「加载已解压的扩展程序」，选择本项目根目录。（之前加载过的，点 HOCHO 卡片上的刷新按钮。）
2. 点工具栏的 HOCHO 图标，打开弹窗。
3. **Key 在这里填**：弹窗右上角齿轮 → 设置 → 第一项「API Key」，粘贴 MOSS API Key，点「连接」，亮绿点即可用。
4. 回到主界面点中间的圆形按钮开始。第一次会打开授权页允许麦克风，完成后点「完成，回到网页」，再点一次 HOCHO 图标就会自动开始。

不需要运行任何额外程序。建议戴耳机：外放的声音可能被麦克风收进去。

## 弹窗上有什么

**底部三样东西**：麦克风、听视频、画面滑块（Auto / 屏幕 / 摄像头）。

| 位置 | 功能 |
|---|---|
| **图标角标** | 抬头看工具栏图标就知道这个网页有没有在生效：**绿点** = 这个网页正在陪看；**黄点** = 正在陪看但看的是别的网页（当前页没生效）；**红「!」** = 出错了；没有角标 = 没在陪看。 |
| 底部 · 麦克风 | 开关你的麦克风 |
| 底部 · 听视频（波形图标） | 默认打开。视频真的出声时，后台多开一条 MOSS 连接专门听视频，把「视频里在发生什么」告诉 TA，所以你问剧情、台词、梗时 TA 答得上来。**会额外计费**；视频静音 30 秒自动断开，有声音再连。图标变青色 = 正在听；灰色划线 = 已关。摄像头模式下不听视频。连不上会自动重试 3 次（2/4/8 秒），还不行就关掉并说明原因，不会一直空转。 |
| 状态文字下方 · 视频类型 | 正在听视频时出现。自动判断是科普、短视频、连续剧、音乐、直播还是通用，可手动改，按视频网址记住。 |
| 状态文字下方 · 切页提示 | 你切到别的网页时会显示：「你现在看的是「…」，不是陪看中的「…」」。画面暂停上传，不会拿错页面；切回去自动恢复。 |
| 状态文字 | 点一下展开「最近的出错记录」（断线原因、权限问题等）；有出错时右边有个小红点。 |
| 角色编辑 · 主动评论 | 安静 / 正常 / 活泼三档，每个角色单独设。先点「测试一下」（约 10 秒，少量额度）：确认 MOSS 会让 TA 主动开口，并显示 TA 说了什么。测试通过后，视频到关键处 TA 会自己接一句；你说话、TA 正在回答时不会插嘴。 |
| 设置 · 网页范围 | 「所有网站自动跟随」默认关：只看你点过 HOCHO 图标的网页，换了网页再点一下图标就跟过去（对话不中断）。打开后切换标签页自动跟随，需要额外授权「读取所有网站」。 |

其他原有功能不变：实时语音对话、一行字幕（只显示你真说过的话，外放的视频声不会被当成你说的）、TA 说话时视频音量自动压低、角色/人设/音色、长期记忆、弹窗关掉也不断、断线自动重试 3 次。

图标沿用 [YIIAI](D:\Git Project\YIIAI) 的小鹿形象，从 Android vector drawable 转成 SVG 后重新居中缩放。要改图标改 `icons/icon.svg`，再运行 `node tools/make-icons.mjs` 生成各尺寸 PNG。

## 权限

| 权限 | 用途 | 何时申请 |
|---|---|---|
| 麦克风 | 语音聊天 | 首次开始 |
| 摄像头 | 让 TA 看到你 | 选摄像头 / Auto 模式时 |
| 当前网页（点图标时的临时授权）+ 标签页声音 | 看网页、听视频 | 不单独弹窗 |
| 读取所有网站（可选） | 切换标签页自动跟随 | 设置里打开「所有网站自动跟随」时 |

## 测试

```
node tests/e2e/run-e2e.mjs            # 弹窗主流程（含听视频按钮、主动评论测试、出错记录）
node tests/e2e/permission-flow.mjs    # 授权流程
node tests/e2e/video-listener-e2e.mjs # 听视频那条连接的协议
npm test                              # 单元测试
```

需要先 `npm install`（只装测试用的 `ws`）。
